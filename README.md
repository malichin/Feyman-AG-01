# Rimessa in Forma

App web personale per rimettersi in forma: allenamento, alimentazione,
abitudini e motivazione in un unico programma integrato.

Nessun backend, nessun account: tutti i dati restano salvati nel browser
(localStorage) del dispositivo su cui apri l'app.

## Come usarla

Apri `index.html` in un browser (doppio click, oppure con un server locale,
es. `python3 -m http.server` nella cartella del progetto).

Al primo avvio viene chiesto un breve profilo (età, altezza, peso, livello di
attività, obiettivo, eventuale dolore articolare, sport praticati) per
calcolare il tuo fabbisogno calorico e adattare il programma.

## Cosa include

- **Dashboard**: riepilogo giornaliero, sfida 30 giorni, obiettivo settimanale.
- **Allenamento**: programma settimanale a rotazione (5 giorni, 10-15 min,
  corpo libero), pensato per essere sicuro per ginocchio e tendini; log delle
  attività sportive esterne (calcio, padel...).
- **Alimentazione**: diario pasti con confronto rispetto al target calorico e
  ai macronutrienti, suggerimenti di pasti in base a cosa hai in frigo.
- **Abitudini**: acqua, sonno, passi, peso, routine mattutina, diario serale
  con statistiche settimanali locali.
- **Profilo**: dati salvati, valori calcolati (BMR/TDEE/BMI) e l'elenco delle
  **fonti scientifiche** su cui si basa ogni consiglio dell'app.

## Nota importante

L'app fornisce linee guida scientifiche generali, non un consulto medico
personalizzato. In caso di dolore persistente o peggiorativo, consulta un
professionista sanitario.
